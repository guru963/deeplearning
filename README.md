# Deep Learning Lab

CS3807 — Deep Learning Laboratory
Shiv Nadar University Chennai · B.Tech Artificial Intelligence & Data Science · Semester V

This repository contains the lab experiments completed for the Deep Learning course. Each experiment lives in its own folder with the notebook, report, and supporting files.

## Experiments

| # | Folder | Title | Summary |
|---|---|---|---|
| 1 | [`lab1`](./lab1) | Perceptron & Single-Layer Neural Network Basics | Implementation of a single-layer perceptron from scratch, covering weight updates, activation functions, and linear decision boundaries as a foundation for multi-layer networks. |
| 2 | [`lab2`](./lab2) | MLP for Multi-Class Image Classification (Fashion-MNIST) | Multi-Layer Perceptron built in TensorFlow/Keras to classify Fashion-MNIST images into 10 classes, including a baseline model, automated hyperparameter optimization with `RandomizedSearchCV`, and a full evaluation/comparison against the tuned model. |

More experiments will be added here as the course progresses.

## Structure

Each lab folder generally follows this pattern:

```
labN/
├── DLLabN.ipynb         # Notebook: implementation, training, evaluation, plots
├── images   # Compiled images
└── README.md            # Lab-specific overview and results
```

See each lab's own README for setup instructions, results, and details specific to that experiment.

## Tech Stack

- Python, NumPy
- TensorFlow / Keras
- scikit-learn, SciKeras
- Jupyter Notebook
- LaTeX (report generation)
